# Проект по системному администрированию

В репозитории представлен скрипт для мониторинга состояния сервера и конфигурация для его запуска в Docker

## Скрипт мониторинга

`script.sh` каждые 5 секунд записывает в `monitor.log` дату и время, состояние ОЗУ, использование дисков и загрузку системы.

## Запуск в Docker

Образ можно собрать и запустить через Docker Compose:

```bash
sudo docker compose up -d --build
```

Контейнер запускает скрипт мониторинга и HTTP-сервер на порту 8080. Проверка:

```bash
curl http://127.0.0.1:8080/monitor.log
```

## Nginx и systemd

В файле `nginx/my-app.conf` хранится конфигурация Nginx. В файле `systemd/my-app.service` хранится настройка запуска контейнера после старта Docker при загрузке системы.
